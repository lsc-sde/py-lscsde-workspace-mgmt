# Installation

You can install the `lscsde-workspace-mgmt` package using pip:

```bash
pip install lscsde-workspace-mgmt
```

To install a specific version:

```bash
pip install lscsde-workspace-mgmt==0.1.13
```

## Dependencies

This package requires:

- Python 3.8+
- pydantic
- kubernetes-asyncio
- pytz
